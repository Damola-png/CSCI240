Five-Week Hard Skill Learning Timeline
Name: Damola Olayefun
Hard Skill: REST API Development Using Python and FastAPI
Goal
Over the next five weeks, I want to learn how to design, build, test and document REST APIs using Python and FastAPI. 
By the end of the five weeks, I want to be comfortable enough with the skill to build a basic REST API on my own and teach someone else how to create one.


Week 1: Understanding APIs and REST

What I will learn:
- What an API is and why APIs are used
- How applications communicate through APIs
- What makes an API a REST API
- HTTP methods: GET, POST, PUT and DELETE
- Requests and responses
- JSON
- Basic HTTP status codes

Week 2 Getting Started With FastAPI
Focus: Build my first API using Python and FastAPI.

What I will learn:
- How to install and set up FastAPI
- How a FastAPI application is structured
- How to run a FastAPI server
- How to create API endpoints
- How to use path and query parameters
- How to return JSON responses


Week 3 Creating and Managing Data
Focus: Learn how REST APIs receive and modify data.

What I will learn:
- POST requests for creating data
- PUT requests for updating data
- DELETE requests for removing data
- Request bodies
- Pydantic models
- Data validation
- Basic error handling


Week 4  Building a Complete REST API
Focus: Combine what I have learned into a complete project.

Project: Task Management REST API
The API will include endpoints such as:
GET    /tasks
GET    /tasks/{id}
POST   /tasks
PUT    /tasks/{id}
DELETE /tasks/{id}


Week 5 Testing, Documentation and Teaching
Focus: Make sure I understand the skill well enough to teach it.
What I will do:
- Test the final API
- Fix bugs and improve the project
- Document how the API works
- Review REST and FastAPI concepts
- Prepare a short beginner-friendly demonstration
- Teach someone how to create a basic FastAPI application and endpoint


Final Outcome
At the end of five weeks, I should be able to independently build a basic REST API using Python and FastAPI. I should understand how clients send requests to an API, 
how the API processes those requests and how data is returned through responses. 
My final Task Management API will serve as evidence of what I learned and as an example I can use when teaching the skill.
